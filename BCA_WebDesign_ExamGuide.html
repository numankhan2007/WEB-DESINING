🏗️ HTML – Introduction

💡
Definition: HTML (HyperText Markup Language) is the standard language used to create web pages. It uses tags to structure content.

Key Features of HTML

  • Not a programming language – it is a markup language
  • Uses tags enclosed in angle brackets < >
  • Tags come in pairs: <tag> (opening) and </tag> (closing)
  • Empty tags have no closing tag: <br>, <hr>, <img>
  • HTML is NOT case sensitive (unlike JavaScript!)
  • Files saved with .html or .htm extension

Structure of an HTML Document

⭐
This is a VERY IMPORTANT topic. You will almost certainly get a 5 or 10 mark question on this.
<!DOCTYPE html>           <!-- tells browser this is HTML5 -->
<html>                     <!-- root element -->

  <head>                   <!-- contains meta information -->
    <title>My Page</title>  <!-- appears on browser tab -->
  </head>

  <body>                   <!-- visible content goes here -->
    <h1>Hello World</h1>
    <p>This is a paragraph.</p>
  </body>

</html>

Parts Explained:

PartPurpose
<!DOCTYPE html>Declaration that tells browser it's an HTML5 document
<html>Root element – wraps everything
<head>Contains title, meta info, CSS links, JS links (NOT visible on page)
<title>Text shown on the browser tab
<body>All visible content: headings, paragraphs, images, forms, etc.

Website vs Webpage

WebpageWebsite
A single document on the webA collection of related webpages
Single .html fileMultiple .html files + CSS + JS
Example: Home page of GoogleExample: www.google.com (entire site)

Static vs Dynamic Website

StaticDynamic
Content doesn't changeContent changes based on user/server
Made with HTML, CSS onlyMade with PHP, Node.js, databases
Faster to loadSlower but more powerful
Example: Personal portfolioExample: Amazon, Facebook

🎨 CSS – Introduction

💡
Definition: CSS (Cascading Style Sheets) is a style sheet language used to control the look and formatting of a document written in HTML. It adds style (fonts, colors, spacing) to web documents.

Key Points About CSS

  • CSS stands for Cascading Style Sheets
  • CSS describes how HTML elements are displayed on screen, paper, or media
  • CSS specifications are maintained by W3C (World Wide Web Consortium)
  • CSS can control the layout of multiple pages all at once

Advantages of CSS

AdvantageExplanation
Handles look and feelControls color, fonts, spacing, layout, background
Saves timeWrite CSS once, reuse across many pages
Pages load fasterLess code = faster download. One CSS rule applies to all matching elements
Easy maintenanceChange one CSS file = all pages update automatically
Easy to learnSimple syntax

Disadvantages of CSS

  • Browser compatibility issues – CSS displays differently in different browsers
  • Multiple levels of CSS can cause confusion
  • Security issues with some CSS properties

CSS Syntax

⭐
Know the CSS syntax diagram perfectly!
selector {
  property: value;
  property: value;
}
PartMeaningExample
SelectorHTML element(s) to styleh1, p, table
PropertyThe style attribute to changecolor, font-size, border
ValueThe value for that propertyred, 12px, solid
h1 {
  color: blue;
  font-size: 24px;
  text-align: center;
}

This means: "Make all h1 headings blue, 24px in size, and centered."

CSS Rule Components

  • Selector – HTML tag being styled (h1, p, div, table)
  • Property – attribute of HTML converted to CSS (color, border)
  • Value – assigned to property (red, #FF0000, rgb(255,0,0))
  • Declaration block = everything inside { }
  • Each declaration ends with a semicolon ;

🎯 CSS – Selectors

⭐
Selectors are VERY IMPORTANT. The 3 types (Type, ID, Class) are guaranteed to appear in the exam!

1. Type Selector (Element Selector)

Selects elements based on their tag name. Applies to ALL elements of that type.

p {
  color: red;
  text-align: center;
}
/* ALL <p> elements will be red and centered */

2. ID Selector

Selects a specific unique element using its ID attribute. Uses # symbol.

🧠
ID must be unique on the page – only ONE element can have a specific id.
#para1 {
  text-align: center;
  color: red;
}
<!-- In HTML: -->
<p id="para1">This paragraph is styled.</p>
<p>This paragraph is NOT affected.</p>

3. Class Selector

Selects elements with a specific class attribute. Uses . (period/dot) symbol. Multiple elements can share a class.

.center {
  text-align: center;
  color: red;
}
/* Applied to any element with class="center" */
<h1 class="center">Red centered heading</h1>
<p class="center">Red centered paragraph</p>

You can also target specific element+class combination:

p.center {
  /* Only affects <p> elements with class="center" */
  color: red;
}

Selector Comparison Table

Type SelectorID SelectorClass Selector
SymbolNone (just tag name)# (hash). (dot)
TargetsAll elements of that tagOne unique elementAll elements with that class
HTML attributeNone neededid="name"class="name"
Example CSSp { }#myId { }.myClass { }
Multiple use?Applies to all p tagsNo (ID is unique)Yes (many elements)

Grouping Selectors

Apply same style to multiple selectors by separating with comma:

h1, h2, h3 {
  color: blue;
  font-weight: normal;
  letter-spacing: .4em;
}
/* h1, h2, h3 all get same style */

📦 CSS – Box Model (Margin, Padding, Border)

⭐
The CSS Box Model is a frequently asked topic. Know margin vs padding vs border!

The CSS Box Model

MARGIN (space outside border)
BORDER
PADDING (space inside border)
CONTENT (text, images, etc.)
PartDefinitionMemory Trick
ContentThe actual text/image inside the elementThe "stuff" inside
PaddingSpace between content and border (inside)Like cushion inside a box
BorderLine surrounding the padding and contentThe box walls
MarginSpace outside the border (between elements)Space around the box

Margin Property

p { margin: 35px; }  /* All 4 sides = 35px */

body { margin: 10px 5px 15px 20px; }
/* Order: TOP RIGHT BOTTOM LEFT (clockwise) */
/* top=10, right=5, bottom=15, left=20 */

p {
  margin-top: 10px;
  margin-right: 5px;
  margin-bottom: 15px;
  margin-left: 20px;
}

Padding Property

p { padding: 35px; }  /* All 4 sides */

h1 { padding: 10px 5px 15px 20px; }
/* TOP RIGHT BOTTOM LEFT */

Border Properties

Border Style (MUST declare first!)

p { border-style: solid; }
p { border-style: dotted; }
p { border-style: dashed; }
p { border-style: double; }
p { border-style: groove; }
h2 { border-style: dotted solid double dashed; }
/* TOP=dotted, RIGHT=solid, BOTTOM=double, LEFT=dashed */

Border Width

h1 { border-style: solid; border-width: thin; }
h2 { border-width: thin medium thick 10px; }
/* Values: thin | medium | thick | px */

Border Color

h1 { border-style: solid; border-color: coral; }
/* Set color by name, hex (#ff0000), or rgb(255,0,0) */
h1 { border-style: solid; border-color: red green blue pink; }
/* TOP=red, RIGHT=green, BOTTOM=blue, LEFT=pink */
⚠️
Important Rule: You MUST declare border-style BEFORE you can use border-color. An element must have a border before you can change its color!

📄 CSS – Methods of Applying CSS

⭐
The 3 ways to apply CSS are asked in every exam! Know all 3 with examples!

3 Ways to Apply CSS

1. Inline CSS (attribute style)

CSS is written directly in the HTML element using the style attribute.

<h1 style="color: blue; font-size: 24px;">
  This is inline CSS
</h1>

<p style="background-color: yellow; color: red;">
  Styled paragraph
</p>
💡
Inline styles are only for the individual tag where specified. Other tags of same type are not affected.

2. Internal CSS (Embedded Style Sheet)

CSS is written inside a <style> tag in the <head> section. Applies to all matching elements on that page.

<!DOCTYPE html>
<html>
<head>
  <style type="text/css">
    body {
      background-color: linen;
    }
    h1 {
      color: maroon;
      margin-left: 20px;
    }
  </style>
</head>
<body>
  <h1>This is a heading</h1>
  <p>This is a paragraph.</p>
</body>
</html>

3. External CSS (Linked Style Sheet)

CSS is written in a separate .css file. Linked to the HTML page using <link> tag. Best for large websites.

<!-- In HTML file (index.html) -->
<head>
  <link
    rel="stylesheet"
    type="text/css"
    href="style.css"
    media="all"
  />
</head>
/* In CSS file (style.css) */
h1, h2, h3 {
  color: #36C;
  font-weight: normal;
  letter-spacing: .4em;
  margin-bottom: 1em;
  text-transform: lowercase;
}

Comparison Table

InlineInternalExternal
LocationIn HTML tagIn <head> <style>Separate .css file
ScopeOne element onlyWhole pageWhole website
ReusabilityNoneSingle pageMultiple pages
Best forQuick fixesSingle page stylingLarge websites
MaintenanceVery difficultModerateVery easy

⚡ JavaScript – Introduction

💡
Definition: JavaScript is a lightweight scripting language designed to add interactivity to HTML pages. It is interpreted (no compilation needed) and runs directly in the browser.

What JavaScript Can Do

  • Give HTML designers a programming tool
  • Put dynamic text into an HTML page
  • React to events (button clicks, mouse movements)
  • Read and write HTML elements
  • Validate data in forms before submitting
  • Detect the visitor's browser
  • Create cookies to store/retrieve information

Java vs JavaScript

JavaJavaScript
Developed by Sun MicrosystemsDeveloped by Netscape
Complex, object-oriented languageLightweight scripting language
Compiled languageInterpreted language (no compilation)
In same category as C/C++Simpler syntax
THESE ARE COMPLETELY DIFFERENT LANGUAGES!

How to Add JavaScript to HTML

<!-- Method 1: In <head> section -->
<head>
  <script type="text/javascript">
    function sayHello() {
      alert("Hello World!");
    }
  </script>
</head>

<!-- Method 2: In <body> section -->
<body>
  <script type="text/javascript">
    document.write("Hello from body!");
  </script>
</body>
🧠
Best Practice: Put functions in <head> so they are loaded before being called. Scripts in <head> are read before the page loads.

📦 JavaScript – Variables & Data Types

What is a Variable?

A variable is a "container" for storing information. Think of it as a box with a label.

Rules for Variable Names

  • Variable names are case-sensitive (y and Y are different!)
  • Must begin with a letter or underscore _
  • Cannot use spaces
  • Cannot use reserved words (like if, for, while)

Declaring Variables

var x;            // declared but empty
var carname;

var x = 5;        // declared with value
var carname = "Scorpio";

// Assign without declaring (auto-declared):
x = 5;
carname = "Scorpio";

Redeclaring Variables

var x = 5;
var x;     // x still equals 5 – value is NOT lost!

JavaScript Data Types

Numbers17, 21, 54.5No quotes. Can be positive or negative
Strings"Hello", 'World'Text in quotation marks
Booleantrue, falseOnly 2 values
NullnullEmpty value (not the same as 0!)
UndefinedundefinedVariable declared but not assigned
⚠️
Important: null ≠ 0. null means the ABSENCE of any value. 0 is a real, calculable number.

🔀 JavaScript – Conditional Statements

Types of Conditional Statements

  1. if – execute code only if condition is true
  2. if...else – execute one block if true, another if false
  3. if...else if...else – check multiple conditions
  4. switch – select one of many blocks to execute

1. if Statement

if (condition) {
  // code if condition is TRUE
}

// Example:
var d = new Date();
var time = d.getHours();
if (time < 10) {
  document.write("<b>Good morning</b>");
}

2. if...else Statement

if (condition) {
  // code if TRUE
} else {
  // code if FALSE
}

// Example:
if (time < 10) {
  document.write("Good morning!");
} else {
  document.write("Good day!");
}

3. if...else if...else Statement

if (condition1) {
  // if condition1 is true
} else if (condition2) {
  // if condition2 is true
} else {
  // if none are true
}

// Example:
if (time < 10) {
  document.write("Good morning");
} else if (time > 10 && time < 16) {
  document.write("Good day");
} else {
  document.write("Hello World!");
}

4. switch Statement

switch(n) {
  case 1:
    // code block 1
    break;
  case 2:
    // code block 2
    break;
  default:
    // if no case matches
}

// Example – Day of week:
var d = new Date();
var theDay = d.getDay(); // 0=Sun, 1=Mon, ..., 6=Sat

switch(theDay) {
  case 5:
    document.write("Finally Friday");
    break;
  case 6:
    document.write("Super Saturday");
    break;
  case 0:
    document.write("Sleepy Sunday");
    break;
  default:
    document.write("Looking forward to weekend!");
}
⚠️
Always use break in switch cases. Without break, execution "falls through" and runs ALL subsequent cases!

🔄 JavaScript – Loops

⭐
Loops are VERY IMPORTANT – all 3 types + break and continue are guaranteed exam topics!

1. for Loop

Use when you know in advance how many times to loop.

for (initialization; condition; increment) {
  // code to execute
}

// Example: Print numbers 0 to 10
var i;
for (i = 0; i <= 10; i++) {
  document.write("The number is " + i);
  document.write("<br />");
}
Output: The number is 0, The number is 1, ... The number is 10

2. while Loop

Use when condition must be true BEFORE executing code.

while (condition) {
  // code to execute
}

// Example:
var i = 0;
while (i <= 10) {
  document.write("The number is " + i);
  document.write("<br />");
  i = i + 1;   // DON'T FORGET TO INCREMENT!
}

3. do...while Loop

Executes code block at least ONCE, THEN checks condition.

do {
  // code to execute
} while (condition);

// Example:
var i = 0;
do {
  document.write("The number is " + i);
  document.write("<br />");
  i = i + 1;
} while (i < 0);   // Condition is false, but loop runs ONCE!
Output: The number is 0 (runs once even though condition i<0 is false)

Loop Comparison Table

forwhiledo...while
Use whenKnow count in advanceCondition basedRun at least once
Condition checkBefore each iterationBefore each iterationAfter each iteration
Minimum runs0 times0 times1 time (always!)

break and continue

// BREAK - exits the loop completely
for (i = 0; i <= 10; i++) {
  if (i == 3) {
    break;  // stops when i=3
  }
  document.write("The number is " + i + "<br>");
}
// Output: 0, 1, 2 (stops at 3)

// CONTINUE - skips current iteration
for (i = 0; i <= 10; i++) {
  if (i == 3) {
    continue;  // skips 3
  }
  document.write("The number is " + i + "<br>");
}
// Output: 0, 1, 2, 4, 5, 6, 7, 8, 9, 10 (skips 3)
🧠
Memory Trick: BREAK = "Break out of jail completely". CONTINUE = "Skip this cell, continue with next".

📝 Complete Question Bank

2-Mark Questions – Quick Answers

2M What is HTML? What does it stand for?
HTML stands for HyperText Markup Language. It is the standard markup language used to create web pages. It uses tags to structure and present content in a web browser.
2M What is an empty tag? Give 2 examples.
An empty tag (also called a void element) is an HTML tag that has no closing tag and does not contain any content between opening and closing tags. Examples: <br> (line break), <hr> (horizontal rule), <img> (image).
2M What is CSS? What does it stand for?
CSS stands for Cascading Style Sheets. It is a style sheet language used to control the look and formatting (presentation) of a document written in HTML. It allows us to add styles like fonts, colors, and spacing to web pages.
2M What is JavaScript? Is it same as Java?
JavaScript is a lightweight scripting language designed to add interactivity to HTML pages. It is an interpreted language. No, JavaScript and Java are completely different languages in both concept and design. Java is a powerful, complex programming language, while JavaScript is a simple scripting language.
2M What is HREF? What does it stand for?
HREF stands for HyperText REFerence. It is an attribute of the <a> (anchor) tag that specifies the URL or path of the linked page. It is mandatory for creating hyperlinks.
2M What is the difference between margin and padding?
Padding is the space between the element's content and its border (inside the element). Margin is the space outside the border, creating distance between elements. Example: padding:35px adds space inside; margin:35px adds space outside.
2M What is the difference between == and === in JavaScript?
== (equal to) compares only the VALUE of two variables. === (strictly equal to) compares both the VALUE and the TYPE. Example: 5 == "5" is true (same value), but 5 === "5" is false (different types: number vs string).
2M What is null in JavaScript?
Null is an empty value in JavaScript. It represents the absence of any value. Null is NOT the same as 0: 0 is a real, calculable number, whereas null means "nothing" or "no value assigned."

5M Explain the structure of an HTML document with example.

An HTML document has a standard structure with the following parts:

  1. <!DOCTYPE html> – Declaration that identifies the document as HTML5
  2. <html> – Root element that wraps all content
  3. <head> – Contains meta information: title, CSS links, JS links (not visible)
  4. <title> – Text shown on browser tab
  5. <body> – All visible content: headings, paragraphs, forms, images

  </head>
  <body>
    <h1>Welcome to HTML</h1>
    <p>This is my first web page.</p>
  </body>

5M Explain the three types of CSS with examples.

1. Inline CSS – Applied directly in the HTML element using style attribute. Applies only to that one element.

<h1 style="color:blue; font-size:20px;">Inline CSS</h1>

2. Internal CSS – Written inside <style> tag in <head> section. Applies to all matching elements on that page.

<head><style type="text/css">
  h1 { color: red; }
</style></head>

3. External CSS – Written in a separate .css file. Linked to HTML using <link> tag. Best for large websites as changes apply sitewide.

<link rel="stylesheet" type="text/css" href="style.css">
5M Explain all three types of loops in JavaScript with examples.

1. for loop – Used when we know the number of iterations in advance.

for (i=0; i<=5; i++) { document.write(i + "<br>"); }

2. while loop – Checks condition BEFORE executing. May not execute at all.

var i=0; while (i<=5) { document.write(i); i++; }

3. do...while loop – Executes code ONCE first, then checks condition. Always runs at least once.

var i=0; do { document.write(i); i++; } while (i<5);
5M Explain CSS selectors: Type, ID, and Class with examples.

1. Type Selector – Selects all elements of a given tag. No special symbol needed.

p { color: red; text-align: center; }

2. ID Selector – Uses # symbol. Selects one unique element with that id.

#para1 { color: red; }   /* HTML: <p id="para1"> */

3. Class Selector – Uses . (dot) symbol. Multiple elements can share a class.

.center { text-align:center; }  /* HTML: <p class="center"> */
5M Explain all types of HTML lists with examples.

There are 3 types of lists in HTML:

1. Unordered List (UL) – Items with bullets (disc, circle, square)

<ul type="disc">

  <li>CSS</li>
</ul>

2. Ordered List (OL) – Items numbered/lettered (1,a,A,i,I)

<ol type="1">
  <li>First</li>
  <li>Second</li>
</ol>

3. Definition List (DL) – Term (<dt>) and its definition (<dd>)

  <dt>HTML</dt>
